# Canes Cuts

Ever typed a whole sentence, looked up, and found gibberish because your
keyboard was set to the wrong language? Canes Cuts fixes that. Select the
text, press *Alt+Shift*, and it flips the text to the other language of
your pair, character for character, exactly as if you had typed it with the
right layout. For example, akuo typed on an English layout becomes
שלום, because those four keys spell "shalom" on a Hebrew layout. It works
in apps and text fields where you can select and replace text.

## Download

1. Open the [latest release](https://github.com/EitanTheGR8C/Canes-Cuts/releases/latest).
2. Download *CanesCuts-Setup.exe* (recommended), or *CanesCuts.exe* if
   you prefer not to install.

Windows may show a security warning for new app downloads. Check that the
file came from this page.

## Install (CanesCuts-Setup.exe)

1. Run the downloaded file.
2. Choose *Install for me only (recommended)* and finish the wizard.
3. Launch Canes Cuts from the Start menu.

You can uninstall it later from Windows Settings > Apps.

## Run without installing (CanesCuts.exe)

Double-click the downloaded file to use the app without installing it.

## Use it

1. The Canes Cuts window opens. Check that the status shows *Running*
   (green dot). If it says Stopped, click *Start*.
2. Pick your two languages in the two dropdowns, for example English and
   Hebrew. Ten languages are available: English, Hebrew, Arabic, Spanish,
   Russian, German, French, Greek, Italian and Portuguese. Your pair applies
   right away and stays until you quit the app.
3. Select the mistyped text and press *Alt+Shift*. The selection is
   replaced with the flipped text, which also stays on your clipboard. If
   nothing is selected, nothing happens.
4. Closing the window keeps Canes Cuts running in the system tray.
   Right-click the tray icon to reopen the window or quit.

## Notes
